# PawGo: A Unified Digital Pet-care and Adoption Management Software

## Project Overview

PawGo is a web application we are developing for our community partner, [People for Animals](https://pfahyd.org/) (PFA).

The goal of this project is to provide PFA with a platform that will help them:
 - List adoptable animals in an easily searchable dashboard visible to community members
 - Receive adoption requests and paperwork through the online platform
 - Disseminate safe and reliable pet-care guidance to community members without requiring staff to manually respond to routine questions

## Stack

PawGo uses a **MERN** stack.

- **UI Framework**: [React](https://react.dev/learn)
- **Backend Runtime**: [NodeJS](https://nodejs.org/en/about)
- **Backend Framework**: [ExpressJS](https://expressjs.com/)
- **Database**: [MongoDB](https://www.mongodb.com/docs)
